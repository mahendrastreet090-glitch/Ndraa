         cURL Request
      


      
      

        

          Opsi 1: Menggunakan URL Gambar
          
        

        
curl -X POST "https://DOMAIN-VERCEL-ANDA.vercel.app/api/lunas" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/gambar.jpg",
    "text": "LUNAS"
  }'

      


      
      

        

          Opsi 2: Menggunakan Base64
          
        

        
curl -X POST "https://DOMAIN-VERCEL-ANDA.vercel.app/api/lunas" \
  -H "Content-Type: application/json" \
  -d '{
    "base64": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
    "text": "LUNAS"
  }'

      

    


    
    

      

         Dokumentasi API
      


      

        
Endpoint

        

          POST /api/lunas
        

      


      

        
Parameter Request (JSON)

        

          

            
              

                Parameter
                Type
                Required
                Keterangan
              

            
            
              

                base64
                string
                conditional
                Base64 string gambar (dengan/tanpa data URI prefix)
              

              

                url
                string
                conditional
                Direct URL file gambar publik
              

              

                text
                string
                no
                Teks stempel custom (default: "LUNAS")
              

            
          

        

        
* Catatan: Harus menyertakan salah satu antara base64 atau url.
